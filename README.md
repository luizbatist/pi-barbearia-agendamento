# PI - Sistema de Agendamento para Barbearia

Projeto Integrador da UNIVESP com o objetivo de desenvolver uma página web simples para agendamento de serviços em uma barbearia.

A proposta é permitir que o cliente escolha:

* o serviço
* o barbeiro
* o horário disponível

Assim ajudando a organizar melhor a agenda e reduzir o tempo de espera.

## Tecnologias

* HTML
* CSS

Demonstrar como soluções simples de tecnologia podem ajudar pequenos negócios a melhorar a organização e o atendimento ao cliente.
